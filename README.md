# 🏛️ Electronic Affidavit System (Kano State Judiciary)

An innovative digital platform for automating affidavit generation, management, and authentication for the Kano State High Court Judiciary.  
Developed by **LegalTech Innovators Ltd**, this system simplifies the affidavit process, ensuring transparency, accessibility, and digital verification.

---

## 🚀 Overview

The **Electronic Affidavit System** allows users to:
- Register using their **NIN** (National Identification Number) for identity verification.  
- Create, manage, and download multiple affidavits digitally.  
- Make secure online payments for affidavit processing.  
- Receive **digitally signed and sealed** affidavits with unique QR verification.  
- Track affidavit status and verify authenticity online.

---

## 🧩 Features (MVP)

### 🔐 Authentication & User Roles
- Role-based access: **User**, **Commissioner**, and **Admin**.
- Users verify their identity using NIN data.
- Details editable only once after the first affidavit submission.

### 📜 Affidavit Management
- Dynamic affidavit creation form.
- Auto-generated affidavit number.
- QR code and digital seal integration.
- PDF generation that mimics the official court format.

### 💳 Payment Integration
- Judiciary payment system or Paystack/Remita gateway.
- Automated receipt generation (PDF and email).

### 🧾 Commissioner Workflow
- Review, approve, or reject affidavits.
- Apply digital signature and seal.
- Send approval notifications to users automatically.

### 👩🏽‍💻 Agent System
- Accredited agents can create affidavits for users who can’t self-serve.
- Admin dashboard for monitoring agent activities.
